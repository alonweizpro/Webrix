# WEBRIX
A gaming browser—simple. Open-source based (Chromium).

דפדפן גיימינג מבוסס Chromium (Electron) עם דגש על ביצועים והתאמה אישית.

## התקנה והרצה
דרוש **Node.js 20 ומעלה** (https://nodejs.org).

```bash
cd Webrix
npm install        # מוריד את Electron (~100MB)
npm start          # מריץ את הדפדפן
```

## בניית קובץ התקנה
```bash
npm run dist:win     # Windows → dist/Webrix Setup 1.0.0.exe
npm run dist:mac     # macOS  → .dmg   (חייב לרוץ על מק)
npm run dist:linux   # Linux  → .AppImage
```

## מה יש בפנים

### ⚡ ביצועים – Control Core (`Ctrl+Shift+P`)
| תכונה | מה היא עושה |
|---|---|
| **RAM Limiter** | מגבלת זיכרון אמיתית: כשהדפדפן חורג, הכרטיסייה הכי פחות בשימוש מורדמת ומשחררת את כל הזיכרון שלה |
| **Tab Sleeping** | כרטיסיות לא פעילות נרדמות אחרי X דקות (ברירת מחדל 15) וחוזרות בלחיצה |
| **Network Limiter** | הגבלת רוחב פס אמיתית ברמת Chromium, כדי שסטרים או הורדה לא יקפיצו לך פינג במשחק |
| **חוסם פרסומות מובנה** | חסימה ברמת הרשת (~140 דומיינים של פרסומות וטראקרים) + הסתרה קוסמטית, עם כיבוי לפי אתר |
| **דף בית בלי תהליך** | כרטיסייה חדשה לא פותחת תהליך Chromium (0MB) |
| **שחזור סשן רדום** | בהפעלה רק הכרטיסייה הפעילה נטענת, השאר נשארות רדומות עד שלוחצים |
| **GPU Boost** | GPU rasterization + zero-copy + עקיפת GPU blocklist |
| **אנימציות חכמות** | חלקיקים ורקעים מונפשים רצים רק כשדף הבית גלוי, מוגבלים ל-30FPS |
| **מדדים חיים** | RAM/CPU עם גרפים, וצריכה לכל כרטיסייה בנפרד |

### 🎮 מצב גיימינג – בוחרים מה פעיל (`Ctrl+Shift+G`)
אין כפתור אחד שמדליק הכל. ב-Control Core יש סעיף "מצב גיימינג" ומדליקים בו כל רכיב בנפרד:
- הרדמה מיידית של כרטיסיות רקע (אחרי דקה)
- הגבלת RAM, עם סף מתכוונן
- הגבלת רוחב פס, עם מהירות מתכווננת
- השתקת כרטיסיות ברקע
- כיבוי אנימציות ואפקטים
- GPU Boost

יש מונה שמראה כמה רכיבים פעילים, וכפתורים "הפעל הכל" ו"כבה הכל".

### 🎨 התאמה אישית – Style Lab (`Ctrl+,`)
- 8 ערכות נושא + עורך צבעים מלא (ראשי, משני, רקע, משטחים, טקסט)
- רקעים: Aurora מונפש, Cyber Grid מונפש, תמונה משלך (נדחסת אוטומטית) או צבע אחיד
- זכוכית: אטימות, טשטוש ועיגול פינות
- 4 סגנונות כרטיסיות, 3 רמות צפיפות, בחירת גופן
- מסגרת RGB מונפשת עם מהירות מתכווננת, חלקיקים אינטראקטיביים, צלילי ממשק מסונתזים
- **Mods:** Dark Mode כפוי לכל אתר, CSS מותאם שמוזרק לכל אתר, ו-CSS שמשנה את ממשק הדפדפן עצמו
- ייצוא/ייבוא ערכות עיצוב כ-JSON, כדי לשתף עם חברים

### 💬 סרגל צד
Discord, Twitch, YouTube, Spotify ו-WhatsApp בפאנל צד ברוחב מתכוונן. אפשר להוסיף כל אתר. קליק ימני פותח: פריקה (שחרור זיכרון), מצב מובייל, הסרה.

### 🕒 כרטיסייה חדשה מותאמת אישית
כפתור "התאמה אישית" בפינת הכרטיסייה החדשה פותח פאנל עם תצוגה חיה:
- **שעון:** ארבעה סגנונות (דיגיטלי, שתי שורות, אנלוגי, ללא), שישה גופנים, עובי 100–900, גודל 50%–170%, ארבעה צבעים, 12 או 24 שעות ושניות.
- **ברכה ותאריך:** הצגה או הסתרה, והשם שלך בברכה.
- **חיפוש:** הצגה או הסתרה, ושלושה סגנונות.
- **קיצורים:** שלושה גדלים, שלוש צורות, ושמות מוצגים או מוסתרים.
- **פריסה:** תוכן במרכז או למעלה, רקע, נתוני ביצועים וחלקיקים.

גופני השעון (Roboto, Montserrat, DM Sans, Bitter) מוטמעים בדפדפן ברישיון SIL OFL. הם מצומצמים לתווי השעון בלבד, כ-43KB בסך הכל.

### ✨ Welcome
- **אשף הגדרה** שנפתח בהפעלה הראשונה ומעביר אותך בשישה שלבים: ערכת נושא, רקע וסגנון, פרופיל גיימינג וסרגל צד.
- **כרטיסיית Welcome קבועה** משמאל לכרטיסיות, עם כל ההגדרות המהירות. אי אפשר לסגור אותה בטעות, ואפשר להסתיר אותה ב-Style Lab.

### עוד
גרירת כרטיסיות, תפריט קליק ימני, השתקה לפי כרטיסייה, הצעות היסטוריה בשורת הכתובת, חיוג מהיר, חיפוש בעמוד, זום, הורדות, מסך מלא לסרטונים ומשחקים (כולל Pointer Lock), 5 מנועי חיפוש.

## מבנה הקוד
```
main.js               תהליך ראשי: חלון, חוסם פרסומות, הגבלת רשת, מדדים, קיצורים
preload.js            גשר IPC מאובטח (contextIsolation + sandbox)
src/main/adblock.js   רשימת חסימה
src/renderer/
  index.html          ממשק
  styles.css          עיצוב (הכל במשתני CSS)
  state.js            הגדרות, ערכות נושא, היסטוריה, מנוע עיצוב
  fx.js               צלילים, חלקיקים, גרפים
  tabs.js             מנוע כרטיסיות + שינה + שחזור סשן
  panels.js           Control Core, Style Lab, סרגל צד, דף בית, חיפוש
  app.js              חיבור הכל + קיצורים + הגדרות מצב גיימינג
```

## הערות
- התחברות עם Google לפעמים נחסמת בדפדפנים מבוססי Electron (מדיניות של Google). התחברות רגילה לאתרים עובדת.
- הגבלת המעבד מתבצעת דרך שינה והאטה של כרטיסיות רקע. אין מגבלת CPU קשיחה באחוזים כמו ב-Opera, כי Chromium לא מאפשר לשלוט בזה.
- תוספי Chrome (Chrome Web Store) לא נתמכים בגרסה הזו.
